# week-planner config (example)

Copy this and fill in your own details. The skill reads these as your saved defaults.

- **Work calendar:** `you@yourdomain.com` (the calendar the skill writes blocks to; needs owner/writer access)
- **Default tracker:** Linear | Jira | Asana | Monday (or leave blank to be asked each run)
- **Working window:** e.g. 9am to 5pm, mornings-leaning
- **Default block length:** the tracker estimate, else 60 min
- **Max blocks per day:** 3
- **Availability:** free (default) | busy
- **Visibility:** visible (default) | private
- **Event color:** your chosen calendar color for blocks
- **Skip list:** recurring checklist-style items to ignore (quick weekly ticks, not focus work)
